# AsukaCode

## 项目简介

AsukaCode 是一款终端 AI 编码助手，基于 **Bun** 运行时和 **TypeScript** 构建，使用 **OpenTUI** 框架打造终端用户界面。它能在命令行中直接提供智能代码辅助，无需离开终端即可获得 AI 驱动的编码建议。

## 主要功能

- **智能代码补全** — 上下文感知的代码建议，提升编码效率
- **终端内交互** — 全程在命令行中操作，无缝融入开发工作流
- **多语言支持** — 覆盖主流编程语言的语法理解和补全
- **轻量高效** — 基于 Bun 运行时，启动迅速、资源占用低

## 技术栈

- **运行时**: Bun
- **语言**: TypeScript
- **UI 框架**: OpenTUI
- **AI 集成**: Claude API
